# Repository Conventions

- Use kebab-case filenames and snake_case project-owned variables and
  functions. Preserve framework-required filenames and external API
  names.
- Colocate tests with the code they exercise: `*.test.ts` (node),
  `*.svelte.test.ts` (browser), `*.e2e.ts` (Playwright).
- Use Vite+ for the toolchain. Align Vite, Vitest, browser providers,
  and coverage with its bundled versions via the pnpm catalog; do not
  introduce a parallel test runtime.
- Import from `#lib` subpaths with explicit file extensions; `$lib` is
  removed in SvelteKit 3.
- `src/lib/components/ui` is generated by shadcn-svelte. Update it
  with the shadcn-svelte CLI rather than hand-editing.
- Mock the Have I Been Pwned API in tests; never send real password
  hashes from test runs.
- Run relevant tests and `pnpm lint` after changes. Report failures
  and validation gaps; do not weaken assertions or skip failures to
  get a green result.

Keep agent instructions limited to durable, non-obvious decisions.
Discover commands, dependencies, configuration, and file layout from
their sources rather than maintaining inventories here.
